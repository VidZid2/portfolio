# Josiah De Asis — Developer Portfolio

A fast, interactive, and beautifully designed developer portfolio built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **TypeScript**.

It showcases my frontend engineering work, experience, projects, skills, and interactive features like an **Ask AI** helper and a command palette (`Ctrl + K`).

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **Database:** Supabase (PostgreSQL)
